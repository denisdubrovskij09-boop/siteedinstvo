# Единство народов — сила России

Статический сайт: index.html, style.css, script.js, папки images/, audio/, fonts/.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в него **всё содержимое этой папки** — так, чтобы index.html лежал в корне.
2. Settings → Pages → Source: Deploy from a branch, Branch: main, папка / (root) → Save.
3. Через минуту сайт откроется по адресу https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/

Дополнительно ничего ставить не нужно: ни Node, ни PHP, ни сборки.
